# SecurePass - Password Generator

A responsive, browser-based password generator built with HTML, CSS, and JavaScript.

## Features

- Adjustable password length from 8 to 32 characters
- Optional lowercase letters, uppercase letters, numbers, and symbols
- Secure browser randomness through the Web Crypto API
- One-click copy button
- Responsive layout for desktop and mobile
- No passwords are stored or sent anywhere

## Run locally

Open `index.html` in a modern web browser. No installation or server is required.
